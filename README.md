# 🎭 Task 22 – Meme Generator

A professional and responsive **Meme Generator** built using HTML5, CSS3, JavaScript, and the Canvas API.

This project allows users to upload an image, add customizable top and bottom text, style the text, preview the meme in real time, and download the final meme as a PNG image.

## 🎯 Objective

The objective of this task is to create an interactive browser-based Meme Generator that allows users to:

- Upload an image
- Add top text
- Add bottom text
- Customize text appearance
- Preview the meme in real time
- Handle long text without overflow
- Download the completed meme as a PNG image

---

## ✨ Features

### 🖼️ Image Upload
- Upload JPG, PNG, or WebP images
- Drag and drop image support
- Uses the user's own image
- No default/mock image required

### ✍️ Text Customization
- Add custom top text
- Add custom bottom text
- Supports long text
- Automatic text wrapping
- Prevents text from overflowing the canvas

### 🎨 Text Styling
- Multiple font options
- Adjustable font size
- Custom text color
- Custom outline color
- Adjustable outline width

### 📍 Text Position
- Standard position
- Center position
- Lower position

### ⚡ Live Preview
All changes are rendered instantly on the HTML5 Canvas.

### 📥 Download
Users can download the generated meme as a PNG image directly from the browser.

### 🔄 Reset
Reset all text, styling, position, and image settings with one click.

### 📱 Responsive Design
The interface is designed to work smoothly on:

- Desktop
- Laptop
- Tablet
- Mobile devices
